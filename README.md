## Development

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/samuel-teshale-portfolio.git
cd samuel-teshale-portfolio
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

The application will be available at:

```text
http://localhost:5340/
```
